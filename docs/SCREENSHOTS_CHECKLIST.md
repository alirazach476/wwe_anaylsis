# Dashboard screenshots checklist

Capture after `python -m wwe_data.api.app` and `cd frontend && npm run dev`:

1. Overview — KPI row + year chart  
2. Wrestlers — rankings + profile  
3. Event Explorer — list + match cards  
4. Match Analytics — type distribution  
5. Championships — bar chart + recent changes  
6. Royal Rumble — entry wins + leaders  
7. Money in the Bank — outcomes pie + table  
8. Survivor Series — match table  
9. Global — choropleth + city table  
10. Machine Learning — registry metrics  
11. Timeline — historical trend  

Store under `docs/screenshots/` when available.
