# Branding assets

- `wwe-logo.svg` — WWE brand mark from [Simple Icons](https://simpleicons.org/) (trademark of WWE; used for identification in this local analytics project).
- `wwe-logo.png` — Wikimedia Commons thumbnail of the WWE logo (trademark of WWE).

Event series themes use configured colors; remote event logo URLs in `assetManifest.ts` point to Wikimedia Commons when available. Missing artwork uses elegant typography fallbacks — logos are never invented.
